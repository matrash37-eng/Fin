# 💰 Мои финансы — Telegram Mini App

Учёт доходов и расходов прямо в Telegram.

- баланс, «заработал» и «потратил» за выбранный месяц и общий баланс за всё время;
- разбивка по категориям с процентами;
- список операций по дням: нажмите на операцию, чтобы изменить или удалить её;
- данные хранятся в Telegram CloudStorage, поэтому сервер и база не нужны, а записи синхронизируются между вашими устройствами;
- цвета берутся из темы Telegram (светлая и тёмная).

## Запуск за 3 шага

### 1. Разместите `index.html` на HTTPS (бесплатно, GitHub Pages)
1. Создайте на GitHub публичный репозиторий, например `finance-app`.
2. Загрузите в него `index.html` (Add file → Upload files).
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту страница будет доступна по адресу `https://ВАШ_НИК.github.io/finance-app/`.

(Подойдут и Netlify, Vercel или Cloudflare Pages: туда достаточно перетащить файл.)

### 2. Привяжите мини-апп к боту в @BotFather
- `/mybots` → ваш бот → **Bot Settings → Configure Mini App → Enable Mini App** → вставьте ссылку из шага 1.
- Готово: в профиле бота появится кнопка «Открыть».

### 3. (Необязательно) Запустите `bot.py`
Скрипт добавит кнопку «💰 Финансы» в меню чата и будет отвечать на /start кнопкой открытия.
```bash
export BOT_TOKEN="123456789:AAF...ваш_полный_токен"
export WEBAPP_URL="https://ВАШ_НИК.github.io/finance-app/"
python3 bot.py
```
Кнопку меню достаточно настроить один раз: после первого запуска она останется, даже если скрипт остановить.

## Настройка категорий
Категории задаются в начале скрипта в `index.html` (объект `CATS`). Новые категории добавляйте **в конец** списка: операции хранят номер категории, и вставка в середину перепутает старые записи.

## Бот, который отвечает на сообщения (бесплатно, Cloudflare Workers)

Код бота — `bot/worker.js`. Он работает в Cloudflare круглосуточно, сервер не нужен.

1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатный план).
2. **Workers & Pages → Create → Create Worker**, назовите его, например, `fin-bot` → **Deploy**.
3. **Edit code**: удалите всё, вставьте содержимое `bot/worker.js` → **Deploy**.
4. **Settings → Variables and Secrets → Add**:
   - `BOT_TOKEN`, тип **Secret** — полный токен из @BotFather (`123456789:AAF...`);
   - `WEBAPP_URL`, тип **Text** — `https://matrash37-eng.github.io/Fin/`.
   Нажмите **Deploy** / **Save**.
5. Откройте в браузере `https://fin-bot.<ваш-поддомен>.workers.dev/setup`, там должны появиться три ✅.
6. Напишите боту что-нибудь.

Если раньше запускали `bot.py` на компьютере, остановите его: одновременно с Cloudflare он работать не будет.
